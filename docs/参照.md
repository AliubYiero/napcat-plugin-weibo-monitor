**目标**

实现一个 weibo 动态监听功能, 需要监听指定用户的 weibo 动态, 并且通过 playwright 生成推送图片

前缀指令为 `#weibo`

微博的访问需要 Cookie, 第一次访问需要用户在 webui 中手动输入 Cookie, 然后后续浏览器访问时自动刷新. 

如果遇到 `https://weibo.com/ajax/statuses/mymblog?uid=7667346930&page=1&feature=0` api 返回 

```
{
    "ok": 0,
    "message": "前方有点拥堵，请登录后使用"
}
```

的内容, 则表示 Cookie 失效了, 需要给超级管理员发送消息.
