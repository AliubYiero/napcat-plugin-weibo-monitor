# Triage Labels

技能使用五个标准 triage 角色。本文件把角色映射到本仓库实际使用的字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全明确, 可由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

本地 markdown issue tracker 中, 这些标签写在 issue 文件的 `Status:` 行。

当技能提到某个角色 (例如「打上 AFK-ready 的 triage 标签」) 时, 使用上表右列对应的字符串。

如需扩展词汇, 直接修改右列。
